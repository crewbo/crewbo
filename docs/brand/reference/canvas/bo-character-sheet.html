Meet Bo

Every teammate gets a Bo. Its eyes are text cursors, and they show what the agent is doing.
character sheet v0.1
01 · THE MARK
crewbo
The logo is Bo mid-glance: eyes shifted right, toward a teammate. Caret eyes are short, flat-ended bars set high and off-centre, so Bo never reads as a pause icon. Below 16 px, use the teammate's colour dot instead.
02 · STATES (LIVE)
Idle Still, with an occasional glance and caret blink
Working Eyes drop and scan, reading the code
Teammate nearby Looks toward the agent working close by
Handoff Two Bos turn to each other while ownership moves
Conflict Eyes go wide, one short shake, then still
Merged A happy squint after a clean merge
Offline Asleep: closed eyes, slow breath, drifting z's
Motion rules Still about 95% of the time. Motion only on real events, each under 300 ms. Idle glance every 10 s in the product (sped up here). Reduced motion turns every animation off.

04 · CREW PANEL SCENES (LIVE)
Writing code Black rectangular glasses, keyboard turned toward Bo. Only the keys move.
Running tests Flask held at eye level: swirl, bubbles, turns green, a puff when tests pass.
Idle Reading a book on the desk. Eyes read slowly; a page turns every few seconds.
Offline Asleep: closed eyes, slow breath, two z's drifting up.
No limbsBo never has hands or arms. Props are worn, rest on a surface, or float at Bo's side.
Still headOne moving thing per Bo. The head stays still; eyes and props carry the life.
Real proportionsBo is the subject. Props are drawn at real size next to Bo, never larger.
Shapes stay distinctNo prop or accessory reuses the tall caret shape of Bo's eyes.
Scenes live in the panelIn code, Bo simply rides the caret as lines are written. Scenes stay in the crew panel.
